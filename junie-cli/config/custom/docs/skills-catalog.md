# Global skills catalog (`~/.junie/skills/`)

Load a skill only when the user intent matches its description/triggers. Prefer project `.junie/skills/` when present.

_Live inventory: `agentmgr skills list` (shim in `~/.junie/custom/bin/`). The list below is a snapshot; descriptions truncated, full text in each `SKILL.md`._

## Quality bar

- Progressive disclosure: procedural `SKILL.md`; deep material under `references/`.
- Naming: hyphen-separated segments; camelCase allowed inside a segment (`fixIssue`, `bestPractices`, `mcpServer`).
- Validate: `~/.junie/skills/dev-agents-skill-create/scripts/validate.py <skill-dir>`.
- Validator: doc-only `sudo`/`exec`/`curl|bash`/`~/.aws`/`MEMORY.md` → WARNING; same inside `scripts/` → CRITICAL. Root wipe pattern ignores `/tmp`.
- OpenAI `agents/openai.yaml` stubs are not used in this Junie home (policy).
- Commands: see `commands-catalog.md` (`/histmgr`, `/sectool`).
