# Claude Specifics for Sec Ops Assetinventory Manage

## Context & Tuning
- Confirm boundary, authoritative discovery sources, owners, classifications, and inventory date.
- Obtain site addresses, network ranges, buckets, and deployment targets from authorized configuration or the user.

## Instructions Overrides
- Never collect credential values or claim full coverage from a single discovery source.

## Performance Notes
- Report unknowns and reconciliation gaps explicitly; do not commit sensitive inventories.
