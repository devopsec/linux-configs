# README structure (default)

Use only if the project lacks a coherent README. Prefer extending the existing outline.

1. Name + one-line purpose  
2. Status badges (only if already used)  
3. Quick start (copy-pasteable)  
4. Requirements / versions  
5. Configuration  
6. Usage / CLI  
7. Development (build, test, lint)  
8. Architecture (short + link deeper)  
9. Contributing / agent docs link  
10. License  

## Quick start quality bar

- Commands work from a clean clone given stated prerequisites
- Paths are repo-relative
- No undocumented required env vars
