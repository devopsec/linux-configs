# 0.8.0 → 0.8.5 and the road to 0.9

0.8.x is meant to be backward compatible with 0.8.0 except where noted; old spellings keep
working with deprecation warnings (`--warn-deprecation=error` to surface them). Sources:
`docs.sh -r 0.8.1` … `-r 0.8.5`.

## 0.8.1 (2026-06)
- `$field.get(a)` / `$field.set(a, b)` deprecated → `a.$field`, `a.$field = b`, `a.$eval($field)`.
- `$$atomic_store`/`$$atomic_load` take an alignment parameter.
- `LinkedHashMap`/`LinkedHashSet` → `OrderedMap`/`OrderedSet` (old names deprecated).
- `@loop_over_ai` → `@loop_over_addresses`; `FixedThreadPool` and old `ThreadPool` deprecated.
- `io::write_all` retries short writes; `spawn` can bind I/O per pipe; `UnboundedChannel` added.

## 0.8.2 (2026-07)
- `@weak` on all declarations; `Foo::is_generic(...)`, `generic_qname`, `generic_args`.
- `own`/`init`/`drop` parameter annotations; generic `constdef`; library `templates`.
- Inline asm no longer stack-aligned by default (`@align` for asm blocks).

## 0.8.3 (2026-08)
- **`@feat(...)` replaces top-level `@if` on non-generic declarations; `$feat` replaces `$feature`.**
  `fn void f() @if(env::WIN32)` → `fn void f() @feat(WIN32)`; `@if` stays for generic-parameter conditions.
- Tracking allocator accepts cross-thread allocations; `json::temp_load` → `json::tload`.
- New: JSON/Object unmarshaling, `range::upto/inclusive/exclusive`, experimental regex.

## 0.8.4 (2026-09) — "the last renaming"
- Keyword renames (old ones accepted through 0.8.x, new ones standard in 0.9.0):
  `faultdef` → `excuse`, `attrdef` → `attrmacro`, `constdef` → `constset`. `excuse { A, B }`
  block form. Stdlib and docs (0.8.5) already use the new names.
- `InStream.read` returns `0` at EOF (never `io::EOF`) and requires a non-empty buffer — loops
  that waited for `io::EOF` from `read` now spin or stop early; `read_byte` still raises EOF.
- `pool::ThreadPool` → `ThreadPoolOld` (behind `-D OLD_THREADPOOL`); new `thread::ThreadPool`
  is the default (`init(mem, max_threads, …)`).
- `@require [param] expr : "msg"` pinpoint contracts; `FooFn::params` returns reflected refs;
  `$reflect(fn).param_struct`; stack-protector/probe options; `Socket.peer_address` etc.

## 0.8.5 (2026-10, patch 0.8.5_1)
- Experimental alternate keywords `cenum`, `faultset`, `distinct` removed (use `constset`,
  `excuse`, `typedef`).
- `@asmname`; `--function-sections`/`--data-sections`; `@section` on local statics.
- Stdlib: `std::gfx`, `IntVec2..4`, `DylibHandle`/`os::dlopen`, `NonNull`/`Nullable`,
  saturating `Duration`/`Time`, macOS/win32 binding reorganization (`std::os::darwin` vs `std::os::macos`).

## Toward 0.9 (planned "syntax freeze")
- Expect `faultdef`/`attrdef`/`constdef` to become errors → migrate now.
- Remaining deprecated aliases (`LinkedHashMap`,
  `json::temp_load`, `env::os_is_posix()` → `$feat(POSIX)`, `env::os_is_darwin()` → `$feat(DARWIN)`)
  are likely removals.
- Track master: `docs.sh -u -r 0.8.6`, nightly `latest-prerelease-tag`.

## Grep targets

`\$[a-z_]+\.(get|set)\(`, `LinkedHash(Map|Set)`, `@loop_over_ai`, `FixedThreadPool|pool::ThreadPool`,
`@if\(` at top level, `\$feature\(`, `json::temp_load`, `\b(faultdef|attrdef|constdef)\b`,
`\b(cenum|faultset)\b`, `catch .*io::EOF` near `.read(`, `env::os_is_(posix|darwin)`.
