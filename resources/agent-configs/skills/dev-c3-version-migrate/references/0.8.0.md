# 0.7.11 → 0.8.0 (released 2026-05-14)

Source: `docs.sh -r 0.8.0`, blog "C3 0.8.0 The Core Language Is Settling", "Unsigned sizes: a
five year mistake", "Let's kill off half the builtins". **Everything deprecated as of 0.7.11 was
removed** — first apply `0.7.md`.

## Signed sizes ("szmageddon")

- `isz` → `sz`; lengths, `Type::size`, container lengths and indices are signed `sz`.
- **Implicit signed↔unsigned conversion removed** (and mixed comparisons). Add explicit casts
  at boundaries; better: change `usz`/`uint` counters and indices to `sz`/`int`.
- Small unsigned types now promote to `int` (C-like value promotion).
- Literal typing aligned with C: decimal = `int` (wider if needed); hex/oct/bin unsigned.
- Unsigned `x >= 0` / `x < 0` comparisons are compile errors (always true/false).

Porting heuristic: grep `usz`, `uint`, `ulong`; keep unsigned only for bit patterns, hashes,
wire formats, C ABI. Watch `for (usz i = n - 1; i >= 0; i--)` style loops and `%`/`/` mixes.

## Types, enums, operators

- `typedef` ("distinct") defaults to **not** converting from literals; `@structlike` removed;
  add `@constinit` where literals must convert: `typedef Port @constinit = ushort;`.
- Enums: no `+`/`-` (use `from_ordinal(e.ordinal + 1)`), `++`/`--` wrap around; enums used as
  indices convert to ordinals; `enum Foo : inline int` removed (use `constdef`/`constset`).
- `@operator(!=)` removed; `@operator(<)` added (with `==` gives all comparisons).
- `??`/`?:` now bind tighter than `+`/`-`: `foo() ?? 0 + 1` is `(foo() ?? 0) + 1` — add parens
  where the old meaning was intended.
- `:` before contract descriptions is mandatory: `@require x > 0 : "positive"`.
- `@extern` removed → `@cname`. `iXX`/`uXX` suffixes removed.
- `Mutex.destroy` and friends return `void` (no `catch`).
- New: `@mustinit`, `untypedlist`, `$expand`, `docgen`, `tags`, nested generics.
