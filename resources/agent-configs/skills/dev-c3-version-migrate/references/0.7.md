# 0.6.x → 0.7.x (0.7.0 released 2025-03-30; 0.7.11 2026-04-06)

Source: `../dev-c3-code-create/scripts/docs.sh -r 0.7.0` … `-r 0.7.11`. 0.7.0 is the big
syntax break; 0.7.1–0.7.11 deprecate further items that **0.8.0 removes**. Porting to 0.8 →
apply everything below, then `0.8.0.md`.

## 0.7.0 syntax changes (old forms are errors)

| 0.6 | 0.7 |
|---|---|
| `def Foo = int;` / `def foo = bar;` | `alias Foo = int;` / `alias foo = bar;` |
| `distinct Id = int;` | `typedef Id = int;` |
| `int!`, `fn void! f()` | `int?`, `fn void? f()` |
| `fault MyFault { A, B }` | `faultdef A, B;` (0.8.4+: `excuse A, B;`) — faults are no longer enum-like types |
| `anyfault` | `fault` |
| `Foo(<int>)`, `module foo(<Type>);` | `Foo{int}`, `module foo{Type};` (→ `module foo <Type>;` in 0.7.9+) |
| `Foo { 1, 2 }` (typed initializer) | `(Foo){ 1, 2 }` or `Foo f = { 1, 2 };` |
| `{| ... |}` expression blocks | macro or helper function |
| `$foreach ($x : $list)` / `$for (...)` / `$switch ($T)` / `$switch` | `$foreach $x : $list:` / `$for ...:` / `$switch $T:` / `$switch:` |
| `$vaexpr(0)` | `$vaexpr[0]` (→ `$vaarg[0]` in 0.8.0) |
| `$or`, `$and`, `$concat` | `\|\|\|`, `&&&`, `+++` |
| `@return!` | `@return?` (with `:` before descriptions) |
| `if (catch foo) { case ...: }` | `if (catch err = foo) { switch (err) { ... } }` |
| `void!` main/test/benchmark | plain `void`/`int` |
| macro `&ref` / `$varef` params | `#expr` params |
| `@operator(construct)`, any-switch, `[?]` | removed |
| enum ↔ int implicit casts | `.ordinal` / `from_ordinal` (casting re-allowed in 0.7.4) |

## 0.7.0 stdlib renames

- `new_*` functions dropped the prefix; `string::new_from_*` → `string::from_*`.
- `mem::temp_new` → `mem::tnew`, `mem::temp_alloc` → `mem::talloc`, `mem::temp_new_array` → `mem::temp_array`.
- `String.to_utf16_copy` → `to_utf16`, `to_utf16_tcopy` → `to_temp_utf16`.
- `@pool(allocator)` → `@pool()` (temp allocator is a variable: `tmem`); threads need `@pool_init()`.
- `Allocator` interface lost `mark`/`reset`; `DynamicArenaAllocator.init` changed; `BackedArenaAllocator` added.
- `os::getcwd`, `os::get_home_dir` take an explicit allocator; `file::load_new` removed.
- `Vec2` etc. aliases removed from std::math (back in 0.7.11); `.length_sq()` → `sq_magnitude()` (→ back to `length_sq` in 0.7.11).
- All hash functions share a common `hash` function name.

## 0.7.1 – 0.7.11 (deprecations → removed in 0.8.0)

| Version | Change | Replacement |
|---|---|---|
| 0.7.1 | operator overloading added | `@operator(+)` etc. |
| 0.7.1 | slice copy `a[1..2] = b` deprecated | `a[1..2] = b[..]` |
| 0.7.2 | `iXX`/`uXX` literal suffixes, `f32/f64` suffixes deprecated | `(ichar)1`, `1f`, `1d` |
| 0.7.2 | `MyEnum.elements`, `SomeFn.params` deprecated | `MyEnum::len`, `$reflect(fn).params` |
| 0.7.3 | `$evaltype` deprecated | `$typefrom` (→ `$Typefrom`) |
| 0.7.4 | const enums `enum Foo : const` added (removed 0.7.10) | `constdef` (→ `constset`) |
| 0.7.4 | `$assignable`, `$is_const`, `allocator::heap()/temp()` deprecated | `$defined(T x = e)`, `$defined`, `mem`/`tmem` |
| 0.7.4 | assignment evaluation order right→left | check code relying on side effects |
| 0.7.5 | `@assignable_to`, `@is_const`, `@typekind`, `@typeis`, `@compact` eq deprecated | `$defined`, `@kindof`, `$Typeof(x) == T` |
| 0.7.5 | `add_array` → `push_all` on lists | |
| 0.7.7 | `@extern` → `@cname` | |
| 0.7.8 | `Enum.associated` → `::members` | |
| 0.7.9 | generics: ad-hoc `<Type>` on declarations; `module foo {Type}` deprecated | `module foo <Type>;`, `struct Foo <T>`, `fn T f() <T>` |
| 0.7.9 | optional creation `FAULT?` deprecated | `FAULT~` (`return io::EOF~;`) |
| 0.7.9 | assignment in conditions needs parens | `if ((x = f()))` |
| 0.7.9 | `int[*][*]` multi-level inference deprecated | spell inner sizes |
| 0.7.9 | Thread/Mutex/CondVar `destroy/lock/unlock/signal/join` become `@maydiscard` (void in 0.8.0) | stop `catch`ing them |
| 0.7.9 | `DString.append_chars` → `append_string`; `append_string(DString)` → `append_dstring` | |
| 0.7.10 | `typedef` / const enums no longer convert from literals | add `@constinit` or cast |
| 0.7.10 | const enums removed | `constdef Foo { A = 1 }` (→ `constset`) |
| 0.7.10 | `unsigned % signed`, `unsigned / signed` need casts | |
| 0.7.10 | streams: `instream.seek` → `set_cursor`/`cursor` (→ `seek` again in 0.8.0); long offsets | |
| 0.7.11 | `SubProcess`, `process::create`, `execute_stdout_to_buffer` deprecated | `Process`, `process::spawn`, `process::run_capture_stdout` |
| 0.7.11 | `std::core::mem::allocator` split | `std::core::mem::allocators` + `std::core::mem::alloc` |
| 0.7.11 | `encode_buffer`/`decode_buffer`, `hex::encode_bytes/decode_bytes` deprecated | `encode_into`/`decode_into` (dst first), `encode_bytes_into` |
| 0.7.11 | `@unaligned_load/store` deprecated | `mem::load` / `mem::store` |
| 0.7.11 | `libc::errno` constants deprecated | `Errno` constset |
| 0.7.11 | matrices column-major; vector method renames (`sq_magnitude` → `length_sq`, …) | |
