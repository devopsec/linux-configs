## Secure-by-default bucket

Since 2023 new buckets have Block Public Access on and ACLs disabled (`BucketOwnerEnforced`); SSE-S3 is default. Still set explicitly:

```bash
B=<bucket>; R=<region>
aws s3api create-bucket --bucket "$B" --region "$R" --create-bucket-configuration LocationConstraint="$R"   # omit config for us-east-1
aws s3api put-public-access-block --bucket "$B" --public-access-block-configuration \
  BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
aws s3api put-bucket-ownership-controls --bucket "$B" --ownership-controls 'Rules=[{ObjectOwnership=BucketOwnerEnforced}]'
aws s3api put-bucket-versioning --bucket "$B" --versioning-configuration Status=Enabled
aws s3api put-bucket-encryption --bucket "$B" --server-side-encryption-configuration \
  '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"aws:kms","KMSMasterKeyID":"alias/<s3-key>"},"BucketKeyEnabled":true}]}'
aws s3api put-bucket-logging --bucket "$B" --bucket-logging-status \
  '{"LoggingEnabled":{"TargetBucket":"<log-bucket>","TargetPrefix":"s3/'"$B"'/"}}'
```

Account-level: `aws s3control put-public-access-block --account-id <account-id> …`. Backups/audit logs: add Object Lock (enable at create with `--object-lock-enabled-for-bucket`; COMPLIANCE mode is irreversible — confirm retention with the user).

## Bucket policies

```json
{"Version": "2012-10-17", "Statement": [
  {"Sid": "DenyInsecureTransport", "Effect": "Deny", "Principal": "*", "Action": "s3:*",
   "Resource": ["arn:aws:s3:::<bucket>", "arn:aws:s3:::<bucket>/*"],
   "Condition": {"Bool": {"aws:SecureTransport": "false"}}},
  {"Sid": "OnlyViaVpce", "Effect": "Deny", "Principal": "*", "Action": "s3:*",
   "Resource": ["arn:aws:s3:::<bucket>", "arn:aws:s3:::<bucket>/*"],
   "Condition": {"StringNotEquals": {"aws:SourceVpce": "<vpce-id>"},
                 "ArnNotLike": {"aws:PrincipalArn": "arn:aws:iam::<account-id>:role/<break-glass>"}}},
  {"Sid": "CrossAccountRead", "Effect": "Allow",
   "Principal": {"AWS": "arn:aws:iam::<other-account-id>:role/<reader>"},
   "Action": ["s3:GetObject"], "Resource": "arn:aws:s3:::<bucket>/shared/*"}
]}
```

- VPCE deny without a break-glass exemption can lock out the console and CI — test with `--dry-run`-style review first and keep an exemption.
- Cross-account needs Allow in bucket policy **and** caller's IAM policy, plus KMS key policy grant for SSE-KMS objects.
- Enforce TLS 1.2+: `"NumericLessThan": {"s3:TlsVersion": "1.2"}` deny.

## Lifecycle

```json
{"Rules": [
  {"ID": "tier", "Status": "Enabled", "Filter": {"Prefix": "data/"},
   "Transitions": [{"Days": 30, "StorageClass": "STANDARD_IA"}, {"Days": 90, "StorageClass": "GLACIER_IR"},
                   {"Days": 180, "StorageClass": "GLACIER"}, {"Days": 365, "StorageClass": "DEEP_ARCHIVE"}]},
  {"ID": "logs", "Status": "Enabled", "Filter": {"Prefix": "logs/"}, "Expiration": {"Days": 90}},
  {"ID": "noncurrent", "Status": "Enabled", "Filter": {},
   "NoncurrentVersionTransitions": [{"NoncurrentDays": 30, "StorageClass": "GLACIER_IR"}],
   "NoncurrentVersionExpiration": {"NoncurrentDays": 180}},
  {"ID": "mpu", "Status": "Enabled", "Filter": {}, "AbortIncompleteMultipartUpload": {"DaysAfterInitiation": 7}},
  {"ID": "markers", "Status": "Enabled", "Filter": {}, "Expiration": {"ExpiredObjectDeleteMarker": true}}
]}
```

`aws s3api put-bucket-lifecycle-configuration --bucket <bucket> --lifecycle-configuration file://lc.json`. Gotchas: IA/Glacier minimum storage durations (30/90/180 days) and per-object minimum size (128 KB) — small objects cost more in IA; consider `INTELLIGENT_TIERING` for unknown patterns. Expiration rules delete data — treat as destructive.

## Replication

Requires versioning on both sides and a replication role.

```json
{"Role": "arn:aws:iam::<account-id>:role/<s3-replication>",
 "Rules": [{"ID": "all", "Status": "Enabled", "Priority": 1, "Filter": {},
   "DeleteMarkerReplication": {"Status": "Disabled"},
   "SourceSelectionCriteria": {"SseKmsEncryptedObjects": {"Status": "Enabled"}},
   "Destination": {"Bucket": "arn:aws:s3:::<dr-bucket>", "StorageClass": "STANDARD_IA",
     "EncryptionConfiguration": {"ReplicaKmsKeyID": "arn:aws:kms:<dr-region>:<account-id>:key/<key-id>"},
     "ReplicationTime": {"Status": "Enabled", "Time": {"Minutes": 15}},
     "Metrics": {"Status": "Enabled", "EventThreshold": {"Minutes": 15}}}}]}
```

Keep `DeleteMarkerReplication` disabled for backup/DR buckets (deletes shouldn't propagate). Existing objects: S3 Batch Replication. Check: `aws s3api head-object --bucket <b> --key <k> --query ReplicationStatus`.

## Presigned URLs

`aws s3 presign s3://<bucket>/<key> --expires-in 900` (GET only). Uploads: SDK `generate_presigned_url("put_object", …)` or presigned POST with conditions (content-length-range, content-type). Max 7 days with SigV4; URL lifetime is capped by the signing credential's lifetime (role sessions!). Treat URLs as bearer secrets.

## Bulk operations (dry-run first)

```bash
aws s3 sync ./build s3://<bucket>/static/ --delete --dryrun        # review, then rerun without --dryrun
aws s3 rm s3://<bucket>/tmp/ --recursive --dryrun                   # DESTRUCTIVE without --dryrun
aws s3 cp big.tar.zst s3://<bucket>/archives/ --storage-class GLACIER_IR
aws s3 ls s3://<bucket>/ --recursive --summarize --human-readable | tail -2
```

Large/scheduled transfers: S3 Batch Operations or DataSync. Bucket size: CloudWatch `BucketSizeBytes` / S3 Storage Lens (cheaper than listing).

## Terraform/OpenTofu

```hcl
resource "aws_s3_bucket" "main" { bucket = var.bucket_name }
resource "aws_s3_bucket_public_access_block" "main" {
  bucket                  = aws_s3_bucket.main.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
resource "aws_s3_bucket_ownership_controls" "main" {
  bucket = aws_s3_bucket.main.id
  rule { object_ownership = "BucketOwnerEnforced" }
}
resource "aws_s3_bucket_versioning" "main" {
  bucket = aws_s3_bucket.main.id
  versioning_configuration { status = "Enabled" }
}
resource "aws_s3_bucket_server_side_encryption_configuration" "main" {
  bucket = aws_s3_bucket.main.id
  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm     = "aws:kms"
      kms_master_key_id = aws_kms_key.s3.arn
    }
    bucket_key_enabled = true
  }
}
# + aws_s3_bucket_lifecycle_configuration, aws_s3_bucket_policy (DenyInsecureTransport)
```

Provider baseline: `hashicorp/aws` `6.70.0` (checked 2026-10-28); commit the exact tested provider selection in the IaC lock file.

## Troubleshooting

| Problem | Fix |
|---|---|
| 403 GetObject | IAM + bucket policy + BPA + KMS key policy; `aws s3api get-bucket-policy-status` |
| 403 PutObject | encryption header required by policy; KMS `GenerateDataKey` permission |
| Presigned 403 | expired, wrong region, or signing session expired |
| Replication idle | versioning off, role/KMS perms, existing objects need Batch Replication |
| Bucket delete fails | versions + delete markers remain (empty via lifecycle, then delete) |
| Lifecycle not acting | filter mismatch; runs asynchronously (up to 48 h) |
