# 0.17 → 0.18-dev (master; moving target)

No release notes exist for master. Sources, in order: `../dev-zig-code-create/scripts/langref.sh -u master <section>`,
<https://ziglang.org/documentation/master/std/>, <https://ziglang.org/devlog/>, and commits on
<https://codeberg.org/ziglang/zig>. Snapshot below is from `0.18.0-dev.828+9da287565`
(2026-10-31) diffed against the 0.17.0 langref. Re-check before relying on it.

## Language

- **Partial operator precedence.** Mixing operators without a defined relative precedence is a
  compile error: `error: ambiguous operator precedence … use parentheses to disambiguate`
  (the note says how 0.17 evaluated it — preserve that meaning when adding parens).
  - Errors: `a or b and c`, `x orelse y == z`, `a catch b orelse c`, `1 ^ 2 | 3`,
    `a << b << c`, `a % b % c`, `a % b * c`, chained comparisons `a == b >= c`,
    bitwise mixed with arithmetic (`a & b + c`).
  - Still fine: `+ - * /` with the usual order, homogeneous chains of `and`, `or`, `&`, `|`,
    `^`, `orelse`, `catch`; prefix ops (`try`, `!`, `-`) bind tighter than everything.
  - Fix mechanically with parentheses; the result is valid 0.17 code too.
- `@splat` accepts a scalar result type (`const x: u32 = @splat(5);`).
- `\u{…}` escapes may encode any code point including surrogates; character literals like
  `'\u{10000}'` are plain integers.

## std / build

- `@import("builtin").cpu/.os/.abi/.object_format` (deprecated in 0.17) are scheduled for
  removal — use `.target.*`.
- Expect deprecated 0.17 aliases (`std.builtin`, `@intFromEnum`, `fmt.allocPrint`,
  `DebugAllocator`, `getLast*`) to start disappearing; port them now.
- Pin dev builds exactly in `build.zig.zon`: `.minimum_zig_version = "0.18.0-dev.828+9da287565"`.

## Detect quickly

```bash
zig build 2>&1 | grep -n 'ambiguous operator precedence'
```
