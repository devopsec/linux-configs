# 0.15 → 0.16 (released 2026-04-13)

Source: <https://ziglang.org/download/0.16.0/release-notes.html>. Verified against 0.16.0 std.
"I/O as an Interface": everything that blocks takes `io: std.Io`. Mechanical but large diff.

## Strategy

1. Switch `main` to `pub fn main(init: std.process.Init) !void` and get `gpa`, `arena`, `io`,
   args and env from `init`.
2. Add `io: std.Io` to every function that (transitively) does file/net/time/sleep/random/sync.
   Libraries take it as a parameter; tests use `std.testing.io`.
3. Replace `std.fs.*`, `std.net`, `std.time`, `std.Thread` sync and `std.crypto.random` per the
   tables, compile, repeat. Don't introduce libc/pthreads as a shortcut.

## Language

| Old | New |
|---|---|
| `@Type(.{ .int = .{ .signedness = .unsigned, .bits = n } })` | `@Int(.unsigned, n)` |
| `@Type(.{ .@"struct" = … })` | `@Struct(layout, BackingInt, names, types, attrs)` — `attrs: *const [n]std.builtin.Type.StructField.Attributes` (`&@splat(.{})` for defaults) |
| `@Type(.{ .pointer = … })` / `.@"fn"` / tuple / enum literal | `@Pointer(size, attrs, Elem, sentinel)`, `@Fn(…)`, `@Tuple(&.{…})`, `@EnumLiteral()`, `@Union`, `@Enum` |
| `@Type(.{ .float/.array/.optional/.error_union/.error_set/.@"opaque" … })` | plain syntax: `f32`, `[n]T`, `?T`, `E!T`, `error{…}`, `opaque {}` |
| `@cImport` | deprecated; `b.addTranslateC(...)` + `@import("c")` (removed entirely in 0.17) |
| runtime vector index `v[i]` | comptime index, or convert to array first |
| in-memory coercion `[4]f32` ↔ `@Vector(4, f32)` through pointers | explicit `@as`/element-wise copy |
| pointers inside `packed struct/union` | not allowed; store an integer address or reorganize |
| packed union with unused bits | not allowed; pad explicitly |
| implicit-backing enum/packed types in `extern` structs | give an explicit backing type (`enum(u8)`, `packed struct(u32)`) |
| `align(@alignOf(@This()))` self-references | now a dependency-loop error; restructure |

Allowed now: small ints coerce to floats (`u8` → `f32`), switch on packed structs/unions and
decl literals, `==` on packed unions, `@floor/@ceil/@round/@trunc` straight to an int result type.

## Process entry, args, env

| Old | New |
|---|---|
| `pub fn main() !void` + `std.heap.DebugAllocator` setup | `pub fn main(init: std.process.Init) !void` — `init.gpa`, `init.arena`, `init.io` |
| `std.process.argsAlloc(gpa)` / `std.process.args()` | `init.minimal.args.toSlice(arena)` / `.iterate()` |
| `std.process.getEnvVarOwned(gpa, "K")` / `getEnvMap` | `init.environ_map.get("K")`; pass `*const std.process.Environ.Map` down |
| `std.process.getCwdAlloc(gpa)` | `std.process.currentPathAlloc(io, gpa)` |
| `std.posix.exit(n)` | `std.process.exit(n)` |
| `std.process.Child.init(argv, gpa)` + `.spawn()` | `std.process.spawn(io, .{ .argv = argv, .stdout = .pipe, … })` |
| `std.process.Child.run(.{ .allocator = gpa, .argv = … })` | `std.process.run(gpa, io, .{ .argv = … })` |
| `std.process.execv(arena, argv)` | `std.process.replace(io, .{ .argv = argv })` |
| `std.posix.mlock*` | `std.process.lockMemory*` |

## Files and directories (`std.fs` → `std.Io.Dir` / `std.Io.File`)

| Old | New |
|---|---|
| `std.fs.cwd()` | `std.Io.Dir.cwd()` |
| `dir.openFile("p", .{})` / `createFile` / `makePath` | `dir.openFile(io, "p", .{})` / `createFile(io, …)` / `createDirPath(io, …)` |
| `file.close()` | `file.close(io)` (same pattern for nearly every method) |
| `std.fs.File.stdout().writer(&buf)` | `std.Io.File.stdout().writer(io, &buf)` (or `File.Writer.init(.stdout(), io, &buf)`) |
| `dir.readFileAlloc(gpa, "p", max)` | `dir.readFileAlloc(io, "p", gpa, .limited(max))` — `error.FileTooBig` → `error.StreamTooLong` |
| `file.readToEndAlloc(gpa, max)` | `var r = file.reader(io, &.{}); r.interface.allocRemaining(gpa, .limited(max))` |
| `std.fs.path.relative(gpa, from, to)` | `relative(gpa, cwd_path, environ_map, from, to)` (pure) |
| `stat.atime` | `?Timestamp` (may be null) |
| `std.fs.getAppDataDir` | removed |
| `*Z` / `*W` path variants (`openFileZ`, `realpathW`, …) | removed — use slice versions |
| tmp / atomic files | `dir.createFileAtomic(io, …)` → `File.Atomic` |

`std.fs` keeps only `path` and size limits from here on.

## Networking, time, randomness, sync

| Old | New |
|---|---|
| `std.net.Address.parseIp("1.2.3.4", p)` | `std.Io.net.IpAddress.parse("1.2.3.4", p)` |
| `std.net.tcpConnectToHost(gpa, host, port)` | `(try std.Io.net.HostName.init(host)).connect(io, port, .{ .mode = .stream })` |
| `address.listen(.{ .reuse_address = true })` | `address.listen(io, .{ .reuse_address = true })`; `server.accept(io)`; `server.deinit(io)` |
| `stream.writer()` / `.reader()` | `stream.writer(io, &buf)` / `stream.reader(io, &buf)` → `.interface` |
| `std.posix.socket/bind/accept/…` | removed: go up to `std.Io.net`, or down to `std.posix.system` |
| `std.time.sleep(ns)` / `std.Thread.sleep(ns)` | `try io.sleep(.fromNanoseconds(ns), .awake)` |
| `std.time.timestamp()` / `milliTimestamp()` | `std.Io.Clock.real.now(io).toSeconds()` / `.toMilliseconds()` |
| `std.time.Timer.start()` / `timer.read()` / `std.time.Instant` | `const t0 = std.Io.Clock.awake.now(io);` … `t0.untilNow(io, .awake)` (Duration) |
| `{D}` format for durations | `duration.format` method → `{f}` |
| `std.crypto.random.bytes(&b)` / `posix.getrandom(&b)` | `io.random(&b)` (fast) / `try io.randomSecure(&b)` (CSPRNG syscall) |
| `std.crypto.random` as `std.Random` | `const src: std.Random.IoSource = .{ .io = io }; const rng = src.interface();` |
| `std.Thread.Mutex` / `Condition` / `RwLock` / `Semaphore` / `ResetEvent` / `Futex` | `std.Io.Mutex` (`.init`, `lock(io)`, `unlock(io)`) / `Io.Condition` / `Io.RwLock` / `Io.Semaphore` / `Io.Event` / `io.futexWait` |
| `std.Thread.Pool` + `WaitGroup` | `var g: std.Io.Group = .init; g.async(io, f, .{…}); try g.await(io);` (`g.cancel(io)` on error paths) |
| `std.once` | removed — avoid globals or hand-roll |
| `std.debug.lockStderrWriter` | `std.debug.lockStderr` / `io.lockStderr(&buf, null)` |

## Containers, fmt, misc std

| Old | New |
|---|---|
| `std.AutoArrayHashMap` / `StringArrayHashMap` / `ArrayHashMap` (managed) | removed; `std.array_hash_map.Auto/String/Custom` (unmanaged, `.empty`) |

| `MemoryPool(T).init(gpa)` | `.empty` / `initCapacity(gpa, n)`; `create(gpa)`, `destroy(ptr)`, `deinit(gpa)` |
| `std.mem.indexOf*`, `lastIndexOf*` | `std.mem.find*`, `findLast*` (old names deprecated); new `cut`, `cutPrefix`, `cutScalar` |

| `std.fmt.FormatOptions` | `std.fmt.Options` |

| `std.leb.readUleb128(reader)` | `reader.takeLeb128(u64)` |
| errors `RenameAcrossMountPoints`/`NotSameFileSystem` / `SharingViolation` / `EnvironmentVariableNotFound` | `CrossDevice` / `FileBusy` / `EnvironmentVariableMissing` |
| fuzz `testOne(ctx, input: []const u8)` | `testOne(ctx, smith: *std.testing.Smith)` |

## Build system

| Old | New |
|---|---|
| `exe.linkSystemLibrary`, `exe.addIncludePath`, `exe.addCSourceFiles`, `exe.linkLibC()` (Compile step) | `exe.root_module.linkSystemLibrary(…)`, `.addIncludePath`, `.addCSourceFiles`, `.link_libc = true` |
| packages fetched only to global cache | also to project-local `zig-pkg/` — add to `.gitignore` |
| editing build.zig.zon to test a local fork | `zig build --fork=/path/to/checkout` |
| hung tests | `zig build test --test-timeout 10s` |
