# 0.13 → 0.14 (released 2025-03; last patch 0.14.1)

Source: <https://ziglang.org/download/0.14.0/release-notes.html>. Verified against 0.14.1 std.

## Language

| Old | New | Notes |
|---|---|---|
| `@typeInfo(T).Struct`, `.Int`, `.Pointer`, `.Enum`, … | `.@"struct"`, `.int`, `.pointer`, `.@"enum"` | `std.builtin.Type` tags lowercased; keywords quoted |
| `ptr_info.size == .One / .Many / .Slice / .C` | `.one / .many / .slice / .c` | `Type.Pointer.Size` renamed |
| `@setCold(true)` | `@branchHint(.cold)` | first statement in the block/function |
| `callconv(.C)` | `callconv(.c)` | `.C` deprecated here, removed in 0.15 |
| `@setAlignStack(n)` | `callconv(.withStackAlign(.c, n))` | |
| `@export(func, .{…})` | `@export(&func, .{…})` | operand is a pointer |
| `@fence(...)` | stronger atomic orderings on the ops | removed |
| anonymous struct types (`.{ .a = 1 }` with no result type has its own type) | tuples/structs unified; give a result type | can change type equality |
| field and decl with the same name | rename one | now an error |
| non-scalar sentinels (`[:.{…}]T`) | scalar sentinel only | |

New, adopt when touching code: decl literals (`.init(…)`, `.empty`), labeled `switch` with
`continue :label value` (state machines), `@FieldType(T, "f")`, `@splat` for arrays, ZON import
(`@import("data.zon")` with a result type).

## Standard library

| Old | New |
|---|---|
| `std.heap.GeneralPurposeAllocator(.{}){}` | `std.heap.DebugAllocator(.{}) = .init` (GPA alias kept until 0.15) |
| — | `std.heap.smp_allocator` (fast release-mode allocator) |
| `Allocator.VTable` without `remap` | custom allocators must implement `remap` |
| managed `std.ArrayList(T).init(gpa)` | start using `std.ArrayListUnmanaged(T) = .empty` (becomes the default in 0.15) |
| `std.mem.page_size` | `std.heap.page_size_min` / `pageSize()` (runtime page size) |
| `std.process.Child.collectOutput(stdout, stderr, max)` | `collectOutput(gpa, &stdout, &stderr, max)` |
| panic handler `pub fn panic(msg, trace, ret_addr)` | `pub const panic = std.debug.FullPanic(myPanicFn);` |

## Build system

| Old | New |
|---|---|
| `build.zig.zon` `.name = "foo"` | `.name = .foo` (enum literal) + `.fingerprint = 0x…` (let `zig build` generate it) |
| `b.addStaticLibrary(.{…})` / `addSharedLibrary` | `b.addLibrary(.{ .linkage = .static/.dynamic, … })` |
| `.root_source_file = …` on `addExecutable` | `.root_module = b.createModule(.{ .root_source_file = …, .target, .optimize })` (old form still works until 0.15) |
| old package hash format | new hash format; re-run `zig fetch --save` if hashes mismatch |

## Grep targets

`\.Struct\b|\.Enum\b|\.Union\b|\.Pointer\b` in `@typeInfo` context, `@setCold`, `callconv\(\.C\)`,
`GeneralPurposeAllocator`, `addStaticLibrary|addSharedLibrary`, `\.name = "` in build.zig.zon.
