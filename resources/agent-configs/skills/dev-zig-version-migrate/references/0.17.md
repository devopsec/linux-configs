# 0.16 → 0.17 (released 2026-10-01)

Source: <https://ziglang.org/download/0.17.0/release-notes.html>. Verified against 0.17.0 std.
Smaller than 0.16. Run `zig fmt` first — it rewrites `@intFromEnum`/`@enumFromInt`.

## Language

| Old | New | Notes |
|---|---|---|
| `@intFromEnum(e)` | `@backingInt(e)` | also packed structs/unions with explicit backing int, tagged unions (active tag). `zig fmt` upgrades |
| `@enumFromInt(i)` | `@fromBackingInt(i)` | arg must be **exactly** the backing type → `@fromBackingInt(@intCast(n))`. Untrusted input: `std.enums.fromInt` |
| `[_]T{x} ** n` / `[1]u8{0} ** N` | `@splat(x)` with a result type | array multiplication removed |
| `@bitCast(extern_struct)` | `@as(*align(1) const U, @ptrCast(&v)).*` or an `extern union` | **compile error** now |
| `@bitCast` on arrays/vectors | review! now logical-bit, endian-agnostic | can change results on big-endian targets **without** a compile error |
| `errdefer \|err\| log(err)` | split: `inner() catch \|err\| { log(err); return err; }` | capture removed |
| `void{}` | `{}` | |
| `i0` | `u0` | |
| `enum {}` (empty) | `enum(noreturn) {}` | |
| `@hasDecl(T, "private")` true in same file | only `pub` decls count | make the decl `pub` or use a different check |
| `.internal` / `.link_once` linkage | omit `@export` / `.weak` | |

New: `@divCeil`, `@SpirvType`, comptime-length slice deref (`s.*` → array) and coercion to
`*const [N]T`.

## Reflection (`@typeInfo`) is struct-of-arrays

```zig
// 0.16
inline for (@typeInfo(T).@"struct".fields) |f| { _ = f.name; _ = f.type; _ = f.default_value_ptr; }
// 0.17
const info = @typeInfo(T).@"struct";
inline for (info.field_names, info.field_types, info.field_attrs) |name, FT, attrs| {
    _ = .{ name, FT, attrs.defaultValue(FT) };
}
```

Enums: `.field_names` + `.field_values`. `std.meta.fields` is a `@compileError`;
`std.meta.fieldInfo/fieldNames/fieldTypes` deprecated. `@Struct/@Union` take
`std.lang.Type.Struct.FieldAttributes` / `Union.FieldAttributes` arrays.

## std

| Old | New |
|---|---|
| `std.builtin` | `std.lang` (`std.builtin` deprecated alias) |
| `std.builtin.OptimizeMode` `.Debug/.ReleaseSafe/…` | `std.lang.Optimize` `.debug/.safe/.fast/.small`; `.runtimeSafety()` |
| `@import("builtin").cpu/.os/.abi/.object_format` | `.target.cpu/.target.os/.target.abi/.target.ofmt` (removed in 0.18) |
| `std.heap.DebugAllocator(.{}) = .init` | `std.heap.SafeAllocator = .init(std.heap.page_allocator, .{})`; `deinit()` returns leak count (`usize`) |
| `std.heap.stackFallback(N, gpa)` / `StackFallbackAllocator(N)` | `var buf: [N]u8 = undefined; var bfa: std.heap.BufferFirstAllocator = .init(&buf, gpa);` |
| `std.fmt.allocPrint(a, fmt, args)` / `allocPrintSentinel` | `a.print(fmt, args)` / `a.printSentinel(fmt, args, 0)` (old ones deprecated) |
| `std.fmt.bufPrintZ` | `std.fmt.bufPrintSentinel` (removed in 0.17) |
| `list.getLastOrNull()` / `list.getLast()` | `list.last()` / `list.last().?`; new `lastPtr()` |
| `std.zon.parse.fromSliceAlloc(T, gpa, src, &diag, .{})` | `std.zon.parse.fromSlice(T, .{ .gpa = gpa, .arena = arena, .source = src, .diagnostics = &diag })`; `updateFromSlice` |
| `std.bit_set.IntegerBitSet/ArrayBitSet/StaticBitSet/DynamicBitSetUnmanaged/DynamicBitSet` | `Integer/Array/Static/Dynamic/DynamicManaged` |
| `.initEmpty()` / `.initFull()` on bit sets, `EnumSet` | `.empty` / `.full` |
| `std.mem.containsAtLeastScalar(T, hay, n, elem)` | **args swapped**: `(T, hay, elem, n)` — compiles silently if types coincide! |
| `std.mem.read/writePackedIntNative/Foreign` | `readPackedInt` / `writePackedInt` |
| `std.ascii.indexOfIgnoreCase*` | `std.ascii.findIgnoreCase*` |
| `std.DoublyLinkedList.pop` | `popLast` |
| `std.gpu` | `std.spirv` |
| `std.Uri` → host lookup | `std.Io.net.HostName.fromUri(uri, &buf)` |
| `heap.memory_pool.AlignedManaged/ExtraManaged` | `memory_pool.Aligned/Extra` |
| `{q}` escaping UTF-8 | passes UTF-8 through; `{qf}` escapes a `format()` output |

`std.mem.eql`/`findDiff` on floats no longer short-circuit on pointer equality (NaN-correct).

## Build system

| Old | New |
|---|---|
| `if (b.args) \|args\| run.addArgs(args);` | `run.addPassthruArgs();` (`b.args` removed) |
| `b.findProgram(.{…})` at configure time | `b.findProgramLazy(.{…})` → `LazyPath` (keeps configure cache pure) |
| `b.lazyDependency("x", .{}) orelse return;` | `const x = try b.dependencyLazy("x", .{});` with `build(...) !void` |
| `b.build_root` (`Directory`) | `b.root` (`Cache.Path`) |
| `opts.addOptionPath(name, dir_path)` for a directory | `addOptionPathDirectory`; `addOptionPathUntracked` to opt out |
| `b.addFmt(.{ .paths = &.{ "src" } })` | `.paths = b.pathList(&.{ "src", "build.zig" })` |
| `@cImport` / `b.addTranslateC` | `zig fetch --save=translate_c "git+https://codeberg.org/ziglang/translate-c#zig-0.17.x"`; `Translator.init(b.dependency("translate_c", .{}), .{ .c_source_file = …, .target, .optimize })` → `.mod` |
| custom build runner (`--build-runner`) | removed; use the Build Server Protocol (`--listen=-`) |
| reading files in build.zig directly | `b.dependOnFileContents/Metadata`, `dependOnDirectoryContents/Metadata` |
| `module.linkSystemLibrary("ws2_32", .{})` on Windows libs without `.pc` | `.{ .use_pkg_config = .no }` (pkg-config is the default) |

`zig fetch` (without `--save`) only fills the global cache again; `zig build` fills `zig-pkg/`.
New `zig fmt --complexity` reports token/AST-node counts.
