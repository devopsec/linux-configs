# 0.14 → 0.15 (released 2025-08; last patch 0.15.2)

Source: <https://ziglang.org/download/0.15.1/release-notes.html>. Verified against 0.15.2 std.
This is the "Writergate" release: the biggest I/O rewrite before 0.16.

## Language

| Old | New |
|---|---|
| `usingnamespace @import("x.zig");` | explicit `pub const a = x.a;` re-exports; conditional decls via `if`/`@compileError`; mixins via a field + `@fieldParentPtr` |
| `async`, `await`, `suspend` usage | removed keywords (`async`/`await`); no replacement until `std.Io` (0.16) |
| `callconv(.C)` | `callconv(.c)` |
| `var n: u32 = undefined; n += 1;` | initialize first — arithmetic on `undefined` is a compile error |
| `const f: f32 = some_u64;` (lossy) | `@floatFromInt` — lossy int→float coercion is an error |
| `"{}"` on a type with `format` | `"{f}"`; `"{}"` no longer calls `format` |
| `pub fn format(self, comptime fmt: []const u8, opts: std.fmt.FormatOptions, writer: anytype) !void` | `pub fn format(self: @This(), w: *std.Io.Writer) std.Io.Writer.Error!void` |
| `asm volatile (… : "memory")` clobber string | typed clobbers `.{ .memory = true }` (`zig fmt` upgrades) |

`switch` on non-exhaustive enums may mix `_` and `else`; `@ptrCast` can turn `*T` into a slice.

## Writergate: std.io → std.Io

| Old (0.14) | New (0.15) |
|---|---|
| `std.io.getStdOut().writer()` | `var buf: [4096]u8 = undefined; var fw = std.fs.File.stdout().writer(&buf); const w = &fw.interface;` … `try w.flush();` |
| `std.io.getStdErr()` | `std.fs.File.stderr()` |
| `file.writer()` / `file.reader()` (unbuffered, generic) | `file.writer(&buf)` / `file.reader(&buf)` returning `File.Writer`/`File.Reader`; use `.interface` (`*std.Io.Writer` / `*std.Io.Reader`). Old ones renamed `deprecatedWriter/Reader` |
| `anytype` writer params, `std.io.AnyWriter`, `GenericWriter` | `w: *std.Io.Writer` (concrete, non-generic) |
| `std.io.fixedBufferStream(&buf)` | `std.Io.Writer.fixed(&buf)` (`.buffered()` for output) / `std.Io.Reader.fixed(bytes)` |
| `std.ArrayList(u8).writer()` | `std.Io.Writer.Allocating.init(gpa)` → `&aw.writer`, `aw.written()` / `toOwnedSlice()` |
| `std.io.bufferedWriter(w)` / `BufferedReader` | buffering is built into every `Io.Writer/Reader` (caller-provided buffer) |
| `std.io.countingWriter` | `std.Io.Writer.Discarding` (`.count`) or track manually |
| `reader.readUntilDelimiterOrEof(&buf, '\n')` | `reader.takeDelimiterExclusive('\n')` (slice into reader buffer) |
| `reader.readAll(&buf)` | `reader.readSliceAll(&buf)` |
| `reader.readAllAlloc(gpa, max)` | `reader.allocRemaining(gpa, .limited(max))` |
| `reader.readInt(T, .little)` | `reader.takeInt(T, .little)` |
| `std.fmt.format(writer, …)` | `writer.print(…)` |
| `std.fmt.fmtSliceHexLower(x)` / `fmtIntSizeBin` / `fmtDuration` | `{x}` / `{Bi}` / `{D}` |
| `std.fmt.Formatter(fn)` | `std.fmt.Alt(Context, fn)` |
| `std.io.SeekableStream`, `BitReader/Writer`, `LimitedReader` | removed — use concrete `File.Reader` APIs |
| bridge for unported code | `old_writer.adaptToNewApi(&buf).new_interface` |

Lifetimes (checked against 0.14.1 / 0.15.2 / 0.16.0 std): **removed in 0.15** —
`bufferedWriter/Reader`, `countingWriter`, `LinearFifo`, `BoundedArray`, `json.stringify`,
`getStdOut/Err/In`; **deprecated in 0.15, removed in 0.16** — `fixedBufferStream`,
`Generic/AnyReader/Writer`, `readUntilDelimiter*`, `std.fmt.format`, `countingReader`, and the
buffer-less `File.reader()/writer()` (renamed `deprecatedReader/Writer`). A 0.15 port can do the
second group incrementally; a port straight to 0.16+ cannot.

**Forgetting `flush()` is the #1 post-migration bug** — output silently disappears.

## Containers

| Old | New |
|---|---|
| `std.ArrayList(T).init(gpa)`; `list.append(x)`; `list.deinit()` | `var list: std.ArrayList(T) = .empty;` `list.append(gpa, x)`; `list.deinit(gpa)` (unmanaged is now the default) |
| want the old managed type | `std.array_list.Managed(T)` (deprecated path) |
| `std.ArrayListUnmanaged(T)` | still an alias of `std.ArrayList(T)` |
| `std.BoundedArray(T, N)` | `var buf: [N]T = undefined; var l: std.ArrayList(T) = .initBuffer(&buf);` + `appendBounded` / `appendAssumeCapacity` |
| `std.fifo.LinearFifo`, `std.RingBuffer` | `std.Io.Reader`/`Writer` buffers, or `std.Deque` (0.16) |
| `std.SinglyLinkedList(T)` generic with `.data` | intrusive non-generic `std.SinglyLinkedList` — embed `node: std.SinglyLinkedList.Node` in your struct, recover with `@fieldParentPtr` |
| `std.json.stringify(v, .{}, writer)` | `std.json.Stringify.value(v, .{}, w)` with `w: *std.Io.Writer` |
| `std.meta.intToEnum(E, i)` | `std.enums.fromInt(E, i)` → `?E` |

## Build system

| Old | New |
|---|---|
| `addExecutable(.{ .root_source_file = …, .target, .optimize })` | **removed**: `.root_module = b.createModule(.{ … })` |
| `addStaticLibrary` / `addSharedLibrary` | removed: `addLibrary(.{ .linkage = … })` |
| `addTest(.{ .root_source_file = … })` | `addTest(.{ .root_module = … })` |
| UBSan always on for C | per-module `.sanitize_c = .off/.trap/.full` |

Fuzz tests in this version take `input: []const u8` (`testOne(ctx, input)`); 0.16 switches to
`*std.testing.Smith`.
