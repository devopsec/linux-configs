# Propagation checklist

| Asset | Copy into project? | Prefer instead |
|-------|--------------------|----------------|
| general coding rules | **Thin overlay** only | Link global + project deltas |
| Full SAD KITTI spec | Link/path reference | Single `spec.md` only if offline needed |
| Language guidelines | Yes if language is primary | Skip unused languages |
| Skill library | Only project-specific skills | Global `~/.junie/skills` |
| Commands | Project repetitive prompts | User commands for personal workflows |
| Security/credential docs | Never copy credential material | Reference process only |

## Done when

- [ ] Fresh agent can find entrypoint in ≤2 hops
- [ ] Domain IF/REFERENCE blocks match actual stack
- [ ] No stale paths
- [ ] README mentions agent docs if contributors use agents
